# Coding-agent guidance

Read cli.py and the affected system before changing behavior. Keep runtime offline.
Use fictional S-series fixtures or documented public reference charts only.
Never add real birth records, private locations, caches, journals, credentials or
personalized reports. Private records belong only in ignored core/people.json.
Use temporary directories for persistence tests and never depend on existing caches.

Preserve third-party LICENSE/NOTICE files and source attribution. Do not bundle
vendor checkouts, generated corpora, node_modules or Swiss Ephemeris data.
Course material is opt-in and retains CC BY-NC-SA 4.0 restrictions.
Keep rules, warnings and approximate-time branches explicit; never silently replace
an approximate range with a confirmed midpoint. Shared-library agreement is not
independent validation. Document frozen numeric fixtures and their provenance.

Run bin/prophet selftest and relevant optional-dependency checks after changes.
Update system docs when flags/defaults change. Check the release file list for
private data and generated content. Do not commit unless the user explicitly asks.
