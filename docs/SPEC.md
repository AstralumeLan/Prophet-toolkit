# 通用设计规格

Prophet 是离线 CLI 计算与检索工具，面向文化研究及可复现算法比较。运行不访问网络，
安装负责依赖、固定上游提交、可选星历和本地语料生成。入口 bin/prophet 使用项目 .venv；
cli.py 注册各体系命令，所有处理器返回可 JSON 序列化的数据。

## 分层与契约

core 负责出生输入、通用坐标、时区/真太阳时、缓存和随机记录。eastern、western、vedic
各自实现规则；紫微通过本地 stdin/stdout JSON Node 桥接，不启动服务。corpus 生成/索引
来源文本，validate 进行声明范围内的交叉比较。tests 为无网络函数式回归。
engine 包含 name/version/rules；新增规则说明可放 rules_ext；warnings 公开降级和不确定性。
辅助查询可返回列表；错误输出 error/message/trace，非零退出。版本更改不能悄悄改变字段语义。

## 输入和不确定性

真实档案与示例档案隔离：优先读私有文件，否则使用明确标虚构的示例。
保留原始日期、时间、时区及精度，计算修正另列。近似时间保留区间，不取中点作为确认时间。
时辰敏感系统按区间分组，天文系统定步长采样并包含端点；必要时按午夜、节气边界细分。
候选标明计算用途，invariants 只表达这些结果间的一致性。规则流派需可选择或明确声明。

## 持久化

命盘缓存需显式请求，按人物、体系和规则哈希命名；测试使用临时目录。
随机记录追加保存方法、问题、seed、时区、时间和结果，相同问题优先复用，重抽明确警告。
私有档案、缓存、日志、个性化输出和凭据都不进入源码发行物。

## 语料与许可

原始文本保持不变，规范化增加书章标识、出处、版本、许可和检索字段。
传统/简体折叠仅用于查找。SQLite FTS5 与短词 LIKE 都按字面匹配，返回同章邻段。
默认排除有非商业限制的课程，仅显式 opt-in 并打印许可才纳入本地索引。
普通 build 清除之前生成的课程。生成语料和星历不发布；保留摘录代码的许可与来源。

## 验证与边界

使用公开图例、虚构样本、历法边界、守恒值、临时缓存往返及缺失依赖路径。
记录独立与共享依赖的区别、数值容差及已知勘误；一致不证明预测有效性。
可选 Chiron 无文件时省略并警告，相关数值测试可说明跳过，其他系统继续运行。
术数输出仅供娱乐与文化研究，不能替代专业判断。
